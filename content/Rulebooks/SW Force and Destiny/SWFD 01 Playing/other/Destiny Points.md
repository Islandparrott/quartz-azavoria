- elevates heroes above commoners
- has light/dark side.  
### [[Destiny Pool]]
- Prep: 
	- each player rolls a Force die at start of session
	- results tallied to become starting pool.  1 symbol is 1 point
### Destiny Point Usage
- Players spend light, GM spends dark
- when you spend 1 point, it flips to the opposite
	- flip occurs after the action is used to stop immediate countering
- can only spend 1 DP/action
- can enhance skill check, upgrade ability into proficiency
- can increase NPC skill check difficulty
#### Narrative usage
- can used to state a "fact" into the narrative
	- land on planet without atmosphere but have no rebreathers.  Can spend a DP to state "Good thing you remembered to pack those rebreathers"
	- if GM agrees it is a good addition, it is added
	- may find spare items, introduce cover nearby
- GM has final say
- players should not be outrageous.
- DP usage meant to reward creativity and roleplay
### Economy in gameplay
- locking points is against the system.  They are meant to be used
- often remind them about destiny points, use if feeling outmatched
### Limits of Luck
- a player/GM can each use 1 DP per check
- only 1 DP may be spent per check per side
