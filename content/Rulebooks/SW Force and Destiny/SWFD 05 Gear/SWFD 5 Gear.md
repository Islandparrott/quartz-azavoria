## [[Black Market]]
- GM Decides what is available
- requires [[Streetwise]] vs [[difficulty]]
- selling requires [[streetwise]].
	- if 3 fail or despair generated, something is wrong.  
		- Buyer robs players, police arrive to arrest them etc.
## [[Trading]]
- Roll [[Negotiation]] check against [[Rarity]] [[difficulty]].
- item sells for 1/4 the price
	- 1/2 for 2 successes
	- 3/4 with 3+ successes
- Can make buy items in a core world and deliver to outer rim for a profit
- Legal items: Negotiation
- Illegal items: Streetwise

# 159 [[Encumbrance]]
---

| size | descriptions                                         |
| ---- | ---------------------------------------------------- |
| 1-2  | Small items, datapads, pistols, knives               |
| 3-4  | Medium, rifles, thermal dets, grappling hooks        |
| 5-6  | Large, cargo crates, repeating rifles, heavy toolbox |
- encumbrance value of 0-5
- represents wait, includes mass, bulk & carryability
- if story demands detail, 1 items are 1enc
	- If stored in a relevant manner, 20 items = 1enc
	- if character bad at management, increase enc
- living being enc = 5 + brawn
	- may be modified depending on species
## [[Encumbrance Threshold]]
- threshold = 5 + brawn
- if over encumbered, +1 setback(black d6) to all agility & brawn for ever point over limit
- if encumbered by amount = brawn, loses free maneuver & takes 2 strain each additional maneuver they take
## Lifting excess
- if lifting singular item greater than encumbrance, make Athletics check
- simple if enc is <= EncT 
	- increase by 1 each point over up to 4
- if assisting, characters add raw brawn to encT
## [[Concealing Items]]
- enc <= 1 are hidden easily
- if inspected, Opposed check: Perception vs Stealth
	- +1 boost to searcher for every point over 1, no cap
	- boosts adjusted based on species, larger species may hide larger items easier
## [[Vehicle Encumbrance]]
- ship holds will have enc threshold
- smuggling panels are hidden around ship, from 2-30 encT

# 166 [[Maintenance]]
- requires time & tools
- 2 hours per difficulty
	- if trying to go quickly, increase difficulty by 1
- without tools, +1 difficulty
- cost equal to type cost * price
	- can reduce by 10 for each triumph on repair check
- NPCs charge the same, wont reduce cost
- if used while damaged, take penalty to usage
- sometimes easier to buy new, but would have to roll TRADING check to find item

| Type     | Difficulty(d8) | Penalty for use    | Cost         |
| -------- | -------------- | ------------------ | ------------ |
| Minor    | 1              | +1 setback(d6)     | .25 * price  |
| Moderate | 2              | +1 difficulty (d8) | .5 * price   |
| Major    | 3              | Unusable           | 1.00 * price |

## Mods
- when furhter changes are wanted
- can improve on performance
- most attachments have series of mods
### Installing Mods
- selects uninstalled mod
- 100c on components/supplies
- needs a tool kit & work bench
- hard(3d8) MECHANICS check
	- if FAILed, can NOT attempt again
	- if FAILs with a DESPAIR, ATTACHMENT is destroyed
- price of additional mods = 100 * # mods after installation
### Lightsaber Mods
- Crystal mods are best ways to mod sabers
- used to find crystals from crystal planets (Ilum, Dantooine, jedha etc)
- extremely rare
- Acquiring a crystal is a quest rather than a transaction
