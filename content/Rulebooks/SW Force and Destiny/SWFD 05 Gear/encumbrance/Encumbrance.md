- encumbrance value of 0-5
- represents wait, includes mass, bulk & carryability
- if story demands detail, 1 items are 1enc
	- If stored in a relevant manner, 20 items = 1enc
	- if character bad at management, increase enc
- living being enc = 5 + brawn
	- may be modified depending on species

## Lifting excess
- if lifting singular item greater than [[Encumbrance]], make [[Athletics]] check
- simple if enc is <= EncT 
	- increase by 1 each point over up to 4
- if assisting, characters add raw brawn to encT
