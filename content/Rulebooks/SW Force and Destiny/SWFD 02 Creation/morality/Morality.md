
- [[Morality]] tracks good vs evil
- can affect decisions, moral compass, [[skills]], [[characteristics]] and [[gear]]
- measure of right and wrong
- measures how good/evil a character is
- shaped by personality. 
- affects use of force
- MOST important characteristic in [[Force and Destiny]]
- allow pc to become better/worse throughout adventure
- described in 2 ways
	- strength, weakness, description: no specific rules.  allows for personality/temperament dev
	- [[Morality Value]]: moral standing, 1-100.
### What is Morality?
- good vs evil
- each morality includes an [[emotional strength]] and [[emotional weakness]]
- Morality is based on a number that represents morality
- encourages interesting/risky choices
- gives decisions a mechanic
- can fall to dark side and be redeemed
- NOT intended to spawn arguments on whether an action is evil
- specific set of guidelines on what damages [[Morality]]
- has randomizing element
- select morality from table
- may randomly generate by: rolling [[Percentile D100]] & compare to table
	- are randomly paired
	- roll once for a [[emotional strength]] and [[emotional weakness]]
- may create new morality for character
### Shared Morality
- PCs may have same [[emotional strength]] and [[emotional weakness]] and goals.
### Starting [[Morality Value]]
- at this point, likely performed good and bad deeds.  
- each character starts with [[Morality Value]] = 50
- Each player chooses one of the following options
	- +10 [[Experience]]
	- +2500 [[credits]]
	- +5 [[Experience]] +1000 [[credits]]
	- increase/decrease [[Morality Value]] by 21

## Morality Thresholds
---
### Dark Side & Redemption
- PCs start as light side users
- transitioning should have strong narrative component
- redemption is not easy
- must make decisions consistently and refrain from using Dark Side to generate force points
### [[Dark Side]] Threshold
- morality drops below 30, become Dark Sider user
- PC generates [[force point]] using [[dark side]] results
- alters group starting [[destiny point]] pool
- uses [[Dark Side]] [[force point]] from [[Force D12]] when using [[force power]]s(pg280)
- if pc wants to generate [[force point]] from [[light side]] results, must flip [[destiny point]] & take [[Strain]] equal to [[force point]] generated
- after rolling for [[destiny point]]s, PC flips 1 [[light side]] [[destiny point]] to the dark side.
- Below 20 [[Morality]]
	- [[strain threshold]] = -1
 	- [[wound threshold]] = +1
- below 10 [[Morality]]
	- [[strain threshold]] = -2
 	- [[wound threshold]] = +2
### [[Light Side Paragon]]
- gained when [[morality]] above 70
- add +1 [[light side]] [[destiny point]] to [[destiny pool]]
- 80 [[morality]]: +1 [[strain threshold]]
- 90 [[morality]]: +2 [[strain threshold]]
